## 按人对账页面 — 备注差值动态计算（最终版）

`pages/user-monthly-summary/user-monthly-summary.vue`，只改备注部分：

### 备注格式（用户最终确认的规则）
- 格式：**`名字 拉水数 回桶数`**（拉水在前，回桶在后），如 `老大 0 400, 我 0 440`
- **数字 0 是占位符，代表该项数据没问题 → 不计算、不显示**
- 只写一个数字时那是**拉水数**（如 `老大 100, 我 120`），回桶视为没问题
- 对比是拿备注里「我」的数字**直接**与对方数字比，不是与订单 quantity/returnedBuckets 比
  - 例：`老大 0 400, 我 0 440` → `回桶：我比老大多40桶`（拉水0跳过）
  - 例：`老大 100, 我 120` → `拉水：我比老大多20桶`（回桶没写跳过）
- 措辞统一为 `我比{名字}多/少X桶`

- `parseRemarkEntries(notes)`：解析成 `{ name, water, returned }`，正则第三个数字可选。
- `buildRemarkDiffSegments(order)`：取备注中「我」与非「我」的条目对比（无「我」条目时回退订单数据）。
  - 返回**结构化段落**而非纯字符串，每个片段带 `highlight` 标记。
  - 任一方为 0 或两者相等 → 不显示该项。
- `monthlyGroups` 合并订单后为每个订单预计算 `order.diffSegments`。
- 右侧备注面板 `remarkComparisonList` 读取合并后订单的 `diffSegments`，按日期每天只显示一行（与截图一致）。
- **比较方向（用户最终确认）**：**客户在前**跟我比较，句式 `拉水：老大比我少记20桶`
- **着色按业务盈亏（用户最终确认）**，片段带 `tone: 'red' | 'green'`，模板用 `getRemarkDiffClass(seg)`
  - **拉水：客户比我少 → 红色**（客户可能漏记，我们亏钱）；客户比我多 → 绿色
  - **回桶：客户比我少 → 绿色**（我们占客户便宜）；客户比我多 → 红色
  - CSS：`.remark-diff-green { color: #059669; }` / `.remark-diff-red { color: #dc2626; }`
  - 只有「多/少」和数字着色，「记」字和「桶」字保持普通色
- **文案**：「多/少」后面加「记」字
- **交互**：`.customer-remark-panel-body` 也绑定 `@tap="toggleCustomerRemarkExpanded"`，点击备注内容可折叠（展开点标题栏）
- **已删除**订单 item 下方的差值显示（用户要求）和废弃的 `parseOrderRemarkComparison` 死代码。
- 编辑/新增/删除订单后调用 `loadAllData()` 刷新数据，确保备注差值实时响应变更。
- 已用 node 验证：只有「多/少」和数字标红，其余文字普通色。
