# 2026-09-02

## 备注解析支持「拉水/回桶」关键词指定项目

`pages/user-monthly-summary/user-monthly-summary.vue`：

- `parseRemarkEntries` 改为返回**原始数字** `{ name, first, second }`（second 未写为 null），不再直接映射成 water/returned。
- 新增 `detectSingleRemarkType(notes)`：备注**只写一个数字**时，用关键词判断归属
  - 含「回桶」且不含「拉水/送水」→ 算**回桶**
  - 含「拉水/送水」或都没写 → 默认算**拉水**
- `buildRemarkDiffRecords` 新增 `pickValue(entry, type)`：
  - 写了两个数字 → 第一个=拉水、第二个=回桶
  - 只写一个数字 → 只有指定项目有值，另一项为 0（代表没问题，**不计算**）

验证通过：`回桶 我100, 老大120` → 只算回桶；`拉水 我100, 老大120` → 只算拉水；`我100, 老大120`（无关键词）→ 默认拉水。
