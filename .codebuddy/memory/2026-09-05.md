## 修复杂事页编译崩溃：残留未闭合函数
- 现象：项目整个编译失败，`vue/compiler-sfc Unexpected token (713:0)`，杂事页 `</script>` 处报错
- 根因：把导出从「两 sheet(报销/工资 tab)」改「单 sheet」时 replace 只删了旧 `buildReimburseSheetRows` 函数的一部分，**残留半个未闭合的旧函数**（`{` 未闭合）
- 定位法：`python3` 逐字符括号配对，找到 script 内位置 12446 的 `{` 未闭合 → 对应 `buildReimburseSheetRows` 行；查文件该处发现旧函数残骸
- 修复：删除残骸（文件 592-618 附近半个 buildReimburseSheetRows），保留新 `buildCombinedSheetRows`
- 教训：replace_in_file 大段替换后必须**用括号配对/语法检查验证闭合**，否则残留半个函数会整包编译失败（lint 和单文件 JS check 未必抓到，需 python 括号扫描）

## 杂事记录：批量录入 + 重复录入检测
`pages/misc-records/misc-records.vue`：

**入口**：顶部 action-group 加「批量」按钮（`openBatchAdd`），与 ＋新增 / 导出 并列

**批量弹窗**：
- 类型切换 chip（报销/工资），`switchBatchType` 切换时清空输入和已解析项（分类型录入，不混合）
- **姓名框填一次**（`batchName`，`openBatchAdd` 默认 `readLastName()`），本批所有行共用；切换类型不清空姓名
- 文本框每行只写「东西 + 金额」：如 `买 1 个气阀 100 元` / `1个电风扇 150 元` / `买螺丝 20 元` / `买3个 气缸 100 元`
- 「解析」→ 预览列表；「提交 N 条」
- 解析：`parseBatch` 用统一 `batchName`，每行整行 `extractAmountFromText` 取金额，报销 desc=`stripAmountText(整行)`，工资 desc 为空
- `stripAmountText`：去掉末尾金额片段（数字+元 / 行尾数字）
- 工资批量：每行只写金额数字（如 `5000`），姓名统一

**重复检测（禁止录入）**：
- dedup key = `type|month|name|desc|amount`（同月+同类型+同人+同内容+同金额）
- `existingRecordKeySet`：本月已有记录 key 集合
- `batchItemDuplicateInfo`：检测 `duplicateInBatch`（本批次内重复）+ `duplicateInDatabase`（本月已存在）
- 重复项预览标红 + 显示「本次重复 / 本月已存在」标签，底部汇总「检测到 N 条重复，已禁止录入」
- `parseBatch` 有重复时 toast 提示；`submitBatch` 只提交 `submittableBatchItems`，全部重复则报错
- 样式：`.batch-textarea/.batch-actions-row/.batch-item(-duplicate)/.batch-item-dup-tag/.batch-dup-summary/.customer-copy-btn-primary`
