## 删除「个人中心」页面（减小包体积）
- 用户明确：pages/profile/profile.vue 完全没用，必须删除
- 已删：pages/profile/ 整个目录；pages.json 中 profile 路由条目；home.vue 中 profile 入口卡片（key/icon/name/desc/iconClass/action）与 pageMap 中 `'profile'` 映射
- 全项目已无 profile 残留引用，lint 0
- **踩坑（CRLF 文件编辑）**：本项目 `pages.json`、`home.vue` 是 **CRLF 行尾**；`replace_in_file` 用 LF 形式的 old_str 匹配时会出现「工具报成功但内容没变/残留碎片」（曾留下 `\t\t\t"path\t{` 导致 pages.json 全文件 Unclosed string 编译失败）。
  → 教训：**编辑 CRLF 文件后必须重新 read_file / 用 python 逐字节校验并 `json.loads` 验证**，不能只信工具返回；碎片要单独再删一次。
