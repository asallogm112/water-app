## 修复编译错误：`Module format "cjs" does not support top-level await`（store.js）
- **现象**：编译报错 `Module format "cjs" does not support top-level await ... at common/store.js:1:0`
- **根因**：实现付款记录时，用 python 插入"付款记录写入本机缓存"那段（含 `await loadPaymentRecords()`）时**锚点选错**——锚点是 `// 工资报销：云端记录 → 本机缓存结构`（refreshAll **函数之后**的顶层注释），导致整段被插到**模块顶层**，形成 top-level await
- **修复**：把该段从顶层移除并插回 `refreshAll` 内部（`return result` 之前），首行补 tab 缩进
- ⚠️ **关键教训**：`node --check` 用 ESM 解析（复制成 .mjs）**不会报 top-level await**，所以之前"语法 OK"是假象
