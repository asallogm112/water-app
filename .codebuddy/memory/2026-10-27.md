- 需求：录入订单输入 `1027 0 0 220` = 10月27号付款 220 元；220 不能进应收；还要生成付款记录
- 实现（pages/batch-order-add/batch-order-add.vue）：

  - `buildParsedItem` / `parseChunk` 增加 `isPayment`（送水0 回桶0 实收>0）

## 补充2：按人对账页付款记录也要显示在「录入当天」（用户追加要求）
- 需求：按人对账页输入 `1027 0 0 220`，记录应显示在录入那天（如 1029），与订单列表一致
- user-monthly-summary.vue 改动：
  - 批量录入 `orders.push`：`displayDate` 由 `createdDate`（错，等于 MMDD）改为 `item.isPayment ? formatDate(new Date()) : createdDate`（付款订单=录入当天）
  - 屏显订单日期标签 `{{ ord.createdDate }}` → `{{ ord.displayDate || ord.createdDate }}`
  - 导出「按天」汇总 `dailySummaryList` 分组键 `ord.createdDate` → `ord.displayDate || ord.createdDate`（按天实收仍用 `createdDate === item.date` 归集，10月27 的 +220 不丢、不双算）
- 自测（录入日=10-29，MMDD=10-27）：按人对账该订单标签显示 10-29 ✅；月总额实收含 220（一次）✅；导出按天行：10-29 组实收=水单（不含220），10-27 组（若有水单）实收含 220 ✅
- lint 全过
- 注意边缘：若某天只有付款无送水（如 10-27 无任何水单只有这笔付款），按月导出「按天」表不会生成 10-27 行（付款被归到 10-29 显示组），但客户总实收仍含 220。订单列表单日视图不受影响（按 createdDate 归集，10-27 总额含 220）。
