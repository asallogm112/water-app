## 修复：order-list 批量提交按钮文案显示「undefined」
- 现象：order-list 弹窗批量录入订单的提交按钮显示「提交这 undefined 笔订单」
- 根因：`pages/order-list/order-list.vue` 的 `batchOrderSubmitText` 这个 computed 在 **script 上下文**里写成了 `submittableBatchOrderItems.length`，漏了 `.value` → 直接读 computed ref 对象的 `.length` 得到 `undefined`。模板里（line 261/294）写 `.length` 是 OK 的（Vue 自动解包），但 script 里必须 `.value.length`
- 修复：line 989 改为 `submittableBatchOrderItems.value.length`
- 对比：`pages/batch-order-add/batch-order-add.vue` 的 `submitBtnText`（line 509）本来就是 `submittableItems.value.length`，正确
- 经验：script 中访问 computed/ref 数组长度务必 `.value.length`；模板中可省略 `.value`

## 付款记录点击跳转「按人对账」（按人+月份定位）
- 需求（最终版，覆盖早期跳 order-list 的方案）：付款记录列表点击 item → 跳转 `user-monthly-summary`，定位到该记录的客户 + 所属月份
- 实现（v2，已修乱码）：
  - `payment-records.vue`：`goToOrderRecord(rec)` 先用 `uni.setStorageSync('payment_record_jump_target', JSON.stringify({userName, month}))` 把客户+月份写入**本地存储**，再 `uni.navigateTo('/pages/user-monthly-summary/user-monthly-summary')`（**不带 URL query**）
  - `user-monthly-summary.vue`：`onLoad` 从 `payment_record_jump_target` 读出并 `removeStorageSync` 清除，填入 `queryUser`/`queryMonth` 并设 `selectedMonth`；客户列表 `watch` 优先用 `queryUser`；onLoad 里还直接 `selectedUser.value = queryUser.value`
- **关键坑（已踩）**：中文 `userName` 走 URL `encodeURIComponent` 后，在 uni-app/微信小程序 `onLoad(options)` 解码会变成**乱码**，导致选中的人匹配不到 → 显示乱码 + "请选择人员"。所以**本场景禁止用 URL 传中文**，一律用本地存储临时传递。
- 约束：两文件纯 LF；lint 0；删除按钮 `.stop` 仍不触发跳转
- 旁：早期 10-03 记录里写过"跳 order-list"的版本，已被本需求覆盖，不再使用
