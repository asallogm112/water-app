## 登录输入框无法输入的真实根因

**uni-app 内置 `<input>` 组件的 100ms 节流(throttle) bug！**

HBuilderX 用 Vite + `@dcloudio/uni-h5` 编译 H5。`<input>` 不是原生 DOM 元素，而是 uni-app 的自定义 Input 组件。
该组件内部对输入事件做了 100ms 节流 + 100ms 防抖，快速打字时大部分 keystroke 被丢弃，字符被吞掉。

**修复方案**：创建 `NativeInput` 自定义组件，用 `h('input', ...)` 渲染原生 `<input>`，绕过 uni-app 的 Input 组件。
在 `pages/login/login.vue` 中实现了该组件，后续其他页面的 input 如果也有类似问题，可以用同样方式处理。

修复了水管家配送系统的 3 个核心业务 Bug：

1. **批量录入实收金额默认 0** (`batch-order-add.vue`)
   - `parseChunk` 中 `!hasExplicitAmount` 判断原本返回 0

   - 修复：将匹配客户/计算单价逻辑移到默认值判断之前

2. **月账单→日账单跳转日期丢失** (`order-list.vue` + `monthly-summary.vue`)
   - `monthly-summary.vue` 的 `navigateToOrderList` 传入 `?date=xxx`
   - 但 `order-list.vue` 的 `selectedDate` 只用了 `today`，未读取 URL 参数
   - 修复：添加 `onLoad` 从 `options.date` 读取
