## 按人对账页面 — 备注面板新增复制按钮

`pages/user-monthly-summary/user-monthly-summary.vue`：

- 备注面板标题栏结构改为：`备注`（左，点它 toggle） + 右侧操作区 `[导出]` `[折叠/展开]`
  - 原来整个 header 绑 `@tap=toggle`，现在拆分：标题和折叠文字各自绑 `@tap.stop="toggleCustomerRemarkExpanded"`，导出按钮绑 `@tap.stop="exportRemarkComparison"`，避免冒泡误触发折叠。
- **导出方式（最终版，替代复制）**：`exportRemarkComparison()` 调用 `exportExcelWorkbook(...).then(showExcelPreviewShareActions)`，弹出操作表 `['打开预览', '分享到微信']`。
- `buildRemarkComparisonSheetRows()`：表头 `日期/项目/我的数量/客户名称/客户数量/差值/对账结果`，每个订单每个差异项一行。
  - **单元格支持样式**：用 `{ value, style }` 结构，style 取值 `'green'`（加粗绿）或 `'red'`（加粗红）。
  - 「项目」「差值」「对账结果」按色调着色；差值列带 `少记X` / `多记X` 前缀。
  - 颜色逻辑与页面备注一致：拉水客户少=红（亏钱），回桶客户少=绿（占便宜）。

## 备注对账 Excel 颜色规则（最终版）
- **项目列固定颜色**：拉水=橙色，回桶=紫色（与盈亏无关）
- **差值/对账结果列**：按盈亏着色（拉水客户少=红亏钱，回桶客户少=绿占便宜），差值带 `少记X`/`多记X` 前缀
- 实现：`buildRemarkComparisonSheetRows()` 中 `typeStyle`（按 type 固定橙/紫）、`diffStyle`（按 tone 红/绿）

## 备注对账 Excel 排序规则
- **先显示所有拉水，再显示所有回桶**；同项目内按时间**升序**
- 实现：先收集所有记录（date+record），`sort` 时 `type` 拉水=0/回桶=1 优先，再按 date 升序（`localeCompare`）

## 备注面板显示规则（用户最终确认，2026-09-01）
备注面板 `remarkComparisonList` 区分三种情况：
1. **能解析出差值**（同时含「我」和对方）→ 显示着色差值段落
2. **能解析出对账条目但差值全为 0**（数据没问题）→ 不显示
3. **完全解析不出**（纯文字/只有一方/空）且备注非空 → **显示备注原文**（`rawNotes`，普通灰色）

- 新增 `canParseRemarkOrder(notes)`：判断是否同时含「我」+「另一方」（`entries.some(非我) && entries.some(我)`）
- `monthlyGroups` 预计算 `order.canParseRemark` 和 `order.diffSegments`
- 模板：`item.segments` 存在用着色段落，否则 `v-else` 显示 `item.rawNotes`
- **「我100, 老大120」只写一个数字 = 只算拉水**，回桶视为没问题不计算（buildRemarkDiffRecords 里 `myReturned !== 0 && other.returned !== 0` 条件保证）
- CSS 新增 `.customer-remark-panel-actions`（flex gap 12px）和 `.customer-remark-export`（绿色胶囊按钮）。

## 重构：对账记录计算共用
- `buildRemarkDiffRecords(order)` — 返回结构化记录 `{ type, myValue, otherName, otherValue, diff, customerLess, tone, text }`，页面展示与 Excel 导出共用，避免两套算法不一致。
- `buildRemarkDiffSegments(order)` — 基于 records 生成页面着色的段落数组。

## 沿用 8-31 定下的备注规则
- 格式 `名字 拉水数 回桶数`，0 是占位符代表没问题，不计算和显示
- 客户在前比较：`拉水：老大比我少记20桶`
- 着色：拉水客户少=红（我们亏钱）；回桶客户少=绿（我们占便宜）
- 点备注内容也能折叠
