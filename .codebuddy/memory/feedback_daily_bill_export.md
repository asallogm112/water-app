月度汇总页（`pages/monthly-summary`）「每日账单图（保存到相册）」导出规则（2026-11-20 最终版）：

1. **排序（所有都统一）**：每日账单图内的订单、月末统计页的人员，**一律按「欠款金额」（应收−实收）降序**，不再区分月结/日结（月结优先规则已被用户取消）。按姓名、应收、回桶、录入时间排都是错的。
2. **每日账单图列**：客户 / 发水 / 回桶 / 应收 / **欠款**。**没有「实收」列**——用户明确「日账单 实收 去掉，也改成欠款」。顶部汇总也是应收 + 欠款，不显示实收。
3. **月末统计页**：按人员列 人员/发水/回桶/欠款金额/欠桶数，底部总计：总发水/总回桶/应收/实收/剩余欠款金额（统计页保留实收，只有每日账单图去掉实收）。
4. **导出流程**：选「每日账单图」→ 生成临时图 → 弹出预览（默认全选、点缩略图微信原生放大、可取消单张/全选/全不选）→ 点「导出所选到相册」才保存。

**Why:** 导出图要发微信给客户对账，按欠款降序能一眼看出谁欠得多；顺序混乱显得不专业、难核对。

**How to apply:** 图片绘制在 `common/daily-bill-image.js`（`drawDay`/`drawSummary`/`generateDailyBillImageFiles`/`saveBillImageFiles`），数据构造在 `monthly-summary.vue` 的 `buildDailyBillDays`/`buildMonthlyBillSummary`/`sortBillOrders`。改排序只按 `debt`（欠款金额）。
